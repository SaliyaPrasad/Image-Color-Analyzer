# Image-Color-Analyzer
このアプリケーションは画像をアップロードし、画像の色や特徴を分析するシステムです。

Libraries

- Streamlit
- OpenCV
- NumPy
- Matplotlib
- Pillow

Functions

✔ Image Upload
✔ Original Image
✔ Grayscale
✔ Edge Detection
✔ RGB Histogram
✔ HSV Analysis
✔ Image Statistics
✔ Average RGB
✔ Download Edge Image

Run

py -m streamlit run app.py
